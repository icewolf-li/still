# Supabase 空配置覆盖防护

用户担心未配置设备通过思源同步把已配置 Supabase Key 覆盖为空。核对后发现：自动加载不会写盘，但手动保存空表单仍可能生成空配置文件。

修复：
- 空配置禁止写入共享的 supabase-connection-v1.json。
- 空 localStorage 迁移值不再写入官方文件。
- 官方文件为空但旧本机配置有效时，使用旧配置修复官方文件。
- 已配置设备收到异常空文件时，重新写入当前有效配置。
- 保留 URL、Key、邮箱后关闭远程同步仍正常保存并同步。

验证：配置迁移/竞态测试 10 项通过；前端与内核类型检查通过；生产构建通过；package.zip 已重新生成。

用户随后要求提交并发布新版本，决定将本轮配置存储迁移和空配置覆盖修复作为 0.1.5 发布，并推送 main 与裸版本标签。
